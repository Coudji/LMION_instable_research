# Portes simples en bois

[← Retour au catalogue des portes](Doors.md)

Cette catégorie regroupe les portes 1x1 en bois actuellement décrites dans le catalogue LMION.

Pour le prototype, les modèles sont regroupés par **style visuel / usage** afin qu'un joueur puisse retrouver une porte plus facilement qu'avec un identifiant technique.

> Les noms ci-dessous sont encore des libellés de travail basés sur le catalogue actuel. Le wiki public devra utiliser les noms réellement affichés en jeu.

## Ce que donnera la version finale

Chaque nom de cette page deviendra un lien vers une fiche individuelle. On pourra donc naviguer simplement :

**Catalogue des portes → catégorie → modèle → toutes ses informations gameplay.**

Les catégories pourront ensuite être affinées si le catalogue devient trop grand : matériau, style, usage, niveau de construction, origine vanilla/mod, etc.
